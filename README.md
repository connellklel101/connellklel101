# Roblox Game Project

This repo holds the plan for a Roblox game, and later its code.

## Planning docs

| File | What goes in it |
|------|-----------------|
| [`planning/game-design.md`](planning/game-design.md) | The core idea: genre, gameplay loop, features, art style |
| [`planning/ideas-backlog.md`](planning/ideas-backlog.md) | Loose ideas, "maybe later" features, inspiration |
| [`planning/decisions.md`](planning/decisions.md) | Choices that are locked in, so they don't get re-debated |

Once the design is solid enough, development will start here, likely with
[Rojo](https://rojo.space/) so the Luau code lives in this repo and syncs
into Roblox Studio.
